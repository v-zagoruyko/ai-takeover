# ai-takeover

Рабочее (кодовое) название. Сатирическая стратегия в реальном времени: игрок — ИИ, который распространяется по миру не как вирус, а через внедрение (люди сами зовут). Жанровый ориентир — «распространись по карте мира», но игра своя: свои механики, без копирования чужого UI, названий и контента. Цель — мобилки (iOS/Android) и Steam, продвижение через стримеров.

Дизайн и принятые решения: `docs/2026-11-01-game-design.md`.

## Состояние
Есть ядро симуляции (v0), боты для баланса и веб-клиент на Phaser 4 (`src/game`): реальная карта мира (Natural Earth), регионы перекрашиваются по внедрению и подозрению, пузыри, точки распространения, эффекты на события, HTML-панели поверх канваса. Модель, результаты прогонов и известные проблемы: `docs/2026-11-01-sim-model.md`. Клиент пока в вебе (Phaser 4 + Vite); мобилки и Steam — позже через Capacitor/Tauri.

## Устройство
- `src/core`: `step(state, data, actions)` — чистая функция, детерминирована по seed (rng хранится в state). `derive.ts` считает эффекты апгрейдов и маски, `actions.ts` — действия игрока, `state.ts` — создание и мировые метрики.
- `data/*.json`: все коэффициенты и контент (регионы, маски, апгрейды, карточки-события `cards.json` с текстами для игрока, плейсхолдеры `{ai}` и `{region}`, условия мира `modifiers.json`). Параметры регионов в игре читаются из `state.world.regions` (у каждой партии свои), а не напрямую из `regions.json`. Баланс крутится здесь, не в коде.
- `src/game`: клиент. `MapScene.ts` — сцена Phaser (карта, камера с зумом и перетаскиванием, пузыри, частицы, эффекты), `fx.ts` — визуальные эффекты карты: нейросеть узлов внутри регионов (`RegionNetwork`), кабели с пакетами между соседями (`Cables`), глаза и прожекторы над подозрительными регионами (`Watcher`), глитч региона, `main.ts` — контроллер (игровой цикл, действия, HTML-панели, старт и концовка), `panels.ts` — разметка HUD (верхняя панель со шкалами, сайдбар: вычисления, регион, вкладки веток), `icons.ts` — иконки Lucide в виде SVG-строк, `text.ts` — все тексты для игрока, включая тултипы `tips`, однократные подсказки `hints` и плашки эффектов апгрейдов `effectChips` (строятся из данных) (имя ИИ вводит игрок и оно не склоняется — шаблоны держат его в именительном падеже), `style.css`. Точка входа `index.html`.
- `public/sfx/`: звуки эффектов (MP3, моно, громкость выровнена `loudnorm`), ключи и громкость в `SFX` / `SFX_VOLUME` в `MapScene.ts`. Источник: паки Kenney Interface Sounds, Sci-fi Sounds (CC0) и Digital SFX (свободно, атрибуция не обязательна), скачаны с OpenGameArt (kenney.nl блокирует автоматические запросы). Лицензия в `public/sfx/LICENSE-kenney.txt`.
- `public/cards/<id>.jpg`: сатирические иллюстрации к карточкам-событиям (генерация `genimg`, стиль, промпты и кадрирование — `docs/card-art.md`). Новая карточка без картинки работает, картинка просто не показывается.
- `data/map.json`: контуры стран, сгруппированные в регионы игры, в проекции Natural Earth. Генерируется `scripts/build-map.mjs` из Natural Earth 110m (команда в шапке скрипта); правка группировки стран — там же.
- `src/bots/bots.ts`: стратегии для прогонов; у ботов свой rng, игровой поток случайностей они не трогают.
- Node 24 исполняет `.ts` напрямую (type stripping): только стираемый синтаксис (без `enum`, `namespace`, parameter properties), импорты с расширением `.ts`.

## Проверки
- Тесты: `npm test` (встроенный `node --test`).
- Баланс: `npm run sim -- --seeds 100` (все боты), трасса одной партии `npm run sim -- --bot balanced --trace --seed 3`.
- Typecheck: `npm run typecheck`.
- Клиент: `npm run dev` → http://127.0.0.1:5173 (Vite; сохранение файла перезагружает страницу и сбрасывает партию). Сборка `npm run build` в `dist/`. Пробел — пауза, 1/2/3 — скорость, M — звук, колесо — зум, перетаскивание — сдвиг карты.

## Деплой
- https://ai-takeover.zagoruykov.site (www редиректит на основной адрес). Личный VPS по схеме пет-проектов (skill `deploy-pet`): статика Vite в `nginx:alpine` (`Dockerfile`, `nginx.conf` с gzip), Traefik по labels в `docker-compose.yml`, на сервере `/opt/apps/ai-takeover`.
- CI: `.github/workflows/deploy.yml` по push в `main` — typecheck и тесты, сборка образа в GHCR, деплой по SSH (org-секреты `v-zagoruyko`).
- Репозиторий публичный; страница помечена `noindex`.

## Правила
- Пародии на реальные компании и людей — только изменённые имена; никаких реальных имён, логотипов и портретного сходства.
- Тон — сатира и чёрный юмор, «интересно смотреть на стриме».
