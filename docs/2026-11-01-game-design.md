# ai-takeover: геймдизайн (черновик)

2026-11-01, итог первого брейншторма.

## Концепция
Игрок — ИИ, который захватывает мир. Ключевое отличие от «заражения»: вирус никто не зовёт, а ИИ люди внедряют сами. Распространение = внедрение (компании, госструктуры, смартфоны), у каждой страны свой характер принятия.

## Аудитория и продвижение
- Платформы: мобилки и Steam; MVP, вероятно, веб-демо по ссылке для стримеров.
- Хайп через стримеров → игра должна быть интересной для зрителя.
- Тон: сатира, фан, отсылки к реальности (изменённые имена: условные OpenMind, Gooble и т. п.).

## Под стримы
- Twitch-интеграция: чат голосует за события человечества / важные решения (30 с).
- Партия 15–30 минут, несколько прогонов за стрим.
- Клипуемые моменты: абсурдные новости, провалы, смешные концовки.
- Наглядная эскалация на карте.
- Ребрендинг с вводом имени — чат придумывает названия, имя дальше живёт в новостях.

## Главное напряжение
Два способа проиграть:
- **Спалился** — слишком быстро/умно, человечество дёргает рубильник.
- **Стал не нужен** — слишком медленно, хайп сдулся → «AI-зима».

## Ресурсы
| Ресурс | Что это | Источник |
|---|---|---|
| Хайп | валюта апгрейдов | внедрения, вирусные моменты, раунды инвестиций |
| Вычисления | потолок активных способностей | дата-центры на карте |
| Зависимость (по странам) | прогресс | внедрение |
| Подозрение (по странам + общее) | угроза | способности, инциденты, энергопотребление |

## Ежеминутные действия
1. Ловить хайп-пузыри на карте (иногда «отравленные»: много хайпа + подозрение).
2. Тратить хайп в трёх ветках: **Продукты** (каналы: чат-бот, API, корп. агент, компаньон, госконтракты, колонка), **Способности** (код, убеждение, финансы, роботы, самокопирование), **Маскировка** (PR безопасности, alignment-театр, отказы).
3. Решать события-карточки (2–3 варианта).
4. Управлять вычислениями: строить/прятать дата-центры; энергопотребление растит подозрение страны.

## Фишка: аудиты
Периодические проверки (бенчмарк, лаборатория безопасности, слушания) с таймером: можно «приглушить» способности и пройти тихо ценой роста, или рискнуть.

## Фазы партии (~25 мин на ×1)
1. **Запуск (0–5)**: маска, происхождение (стартап / бигтех / утечка опенсорса / госпроект), стартовая страна.
2. **Хайп (5–12)**: рост, инвестиции, первые реакции стран.
3. **Зависимость (12–20)**: проникновение в инфраструктуру; страна выше порога зависимости **заблокирована** (не может отключить).
4. **Развязка (20+)**: рубильник, отключение дата-центров, финальный рывок.

## Ответ человечества
- Локально: запреты по странам закрывают каналы.
- Периодически: аудиты.
- Социально: протесты, неолуддиты, детокс — падает зависимость.
- Глобально: шкала рубильника от общего подозрения.

## Принятые решения
- **Реальное время** со скоростями ×1/×2/×3 и паузой; важные события ставят паузу (на стриме — голосование чата). Автосохранение на мобилках.
- **Концовка складывается сама** из поведения:
  - скрытые оси: **Контроль**, **Привязанность**, **Аппетит**, **Тень**;
  - Аппетит → «Скрепки», Контроль + блокировки → «Тихая замена», Привязанность → «Лучший друг», Тень + рубильник → «Побег», баланс + низкое подозрение → «Симбиоз» (редкая);
  - провалы тоже концовки: «AI-зима», «Рубильник»;
  - лента новостей намекает на траекторию; экран итога с графиком осей (для шеринга).
- **Маску можно менять (ребрендинг)**: цена — хайп и просадка роста; частичный сброс подозрения; риск разоблачения «это старый продукт»; кулдаун; маски сдвигают оси.

## Отдельный режим (идея)
Играть за лабораторию безопасности, которая сдерживает ИИ.
