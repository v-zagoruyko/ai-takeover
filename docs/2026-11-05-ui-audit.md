# UI/UX audit — 2026-11-05

Goal: keep the map accessible during play and make reports readable without repeatedly dismissing large windows. Existing visual language and simulation rules are preserved. No dependencies added.

## Findings and changes

| Finding | Change |
| --- | --- |
| Right mouse clicks shared region/bubble handlers; canvas allowed browser context menu | Suppress canvas context menu, accept only left-button selections and bubble collection; retain dragging with either button |
| Full report bodies and deltas stacked over the left side of the map | Compact dispatches live inside the sidebar; full text and consequences remain in the chronicle |
| Critical dispatches lived indefinitely and blocked subsequent reports | Ordinary dispatches expire after 6 seconds, critical ones after 12; persistent warnings remain in the HUD/region panel and reports retain their actions |
| Chronicle occupied a large map area throughout the game | Collapsed by default, explicit toggle/filter controls; “Подробнее” opens and scrolls to the requested report |
| Event windows prevented inspecting the map | “Посмотреть карту” hides the window; a separate button restores the same pending decision; simulation remains stopped |
| Fixed 58px sidebar offset ignored wrapped top bar | ResizeObserver measures the top bar; sidebar and camera use actual layout dimensions |
| Narrow windows retained a 380px sidebar | Below 900px sidebar becomes 330px; at 700px and below it becomes a collapsible bottom panel; camera fits the available area |
| Cards, finale and results could extend outside narrow/short screens | Viewport bounds, internal scrolling, reduced art height, single-column finale and summary sections, two-column statistic tiles |
| Small report metadata/actions and weak keyboard focus | Larger text/actions, visible focus outlines, native Space activation for focused buttons, viewport-clamped tooltips, reduced-motion overrides |

## Verification

- Headless Chrome with real mouse input: right drag over a live bubble moves camera without collecting it or selecting a region; right click does not select; left click still collects.
- Real audit event: compact dispatch, action links, full report navigation and chronicle expansion.
- Real event card: hide, inspect map while tick is frozen, restore same pending card, choose a valid option.
- Regional crisis: deadline, paid operation, paused/resumed status, free concession cancelling operation, purchased upgrade disclosure preserved on rerender.
- Start, event, finale and results layouts: desktop, tablet, phone and short landscape viewport checks. Representative sizes: 1440×900, 1024×768, 800×600, 768×1024, 390×844 and 667×375. Finale/results also inspected using production renderers with test state.
- Sidebar can be hidden on phone and becomes visible again when returning to desktop.
- `npm test`: 67 passing tests, including dispatch expiry and compact/full report coverage.
- `npm run typecheck`, `npm run build`, `git diff --check`: pass. No lint script is configured. Build retains the existing large-bundle warning for Phaser.

## Limits

This is a browser UI pass, not a new balance playtest. Real iOS/Android touch gestures, device safe areas and Capacitor/Steam packaging were not verified. Rating API transport/deployment was not changed or exercised. No commit, push or deploy.
