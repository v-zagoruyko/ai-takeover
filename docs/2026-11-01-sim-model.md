# ai-takeover: модель симуляции (черновик v0)

2026-11-01. Ядро без графики: состояние мира, формулы такта, условия победы и поражения. Все коэффициенты (`k_*`, пороги) стартовые, живут в конфиге и подбираются прогонами ботов. Геймдизайн: `2026-11-01-game-design.md`.

## Время
- 1 такт = 1 игровой день; на ×1 — 1 такт в секунду (×2, ×3 — чаще).
- Целевая длина партии: 1200–1600 тактов (20–27 мин на ×1).

## Мир: регионы
15–25 регионов (не страны поштучно). Статичные параметры:

| Параметр | Диапазон | Смысл |
|---|---|---|
| `pop` | доли, сумма = 1 | вес региона в мировых метриках |
| `wealth` | 0..1 | сколько хайпа даёт внедрение |
| `tech` | 0..1 | скорость принятия |
| `openness` | 0..1 | терпимость к ИИ: гасит подозрение, отодвигает запреты |
| `energy` | ед. | сколько вычислений можно разместить без подозрений |
| `archetype` | `corp` / `state` / `regulator` / `emerging` | какие каналы работают лучше |
| `links` | веса к соседям | граф перетекания (торговля, соцсети) |

Архетипы (стартовые ориентиры):
- `corp` (условные Штаты): tech 0.9, openness 0.7, лучше всего API и корп. агенты.
- `state` (условный Китай): tech 0.8, openness 0.3, работает только госканал, но после входа зависимость растёт быстро.
- `regulator` (условный ЕС): tech 0.8, openness 0.4, рано вводит запреты, позже массово принимает.
- `emerging` (Индия, Африка, LatAm): tech 0.4–0.6, openness 0.8, дешёвые потребительские продукты.

## Состояние

На регион `i`:
- `a` — внедрение 0..1 (доля использующих);
- `d` — зависимость 0..1;
- `s` — подозрение 0..1;
- `banned`, `locked` — флаги;
- `dc` — построенные дата-центры (ед. вычислений).

Глобально:
- `H` — хайп (валюта);
- `patience` — терпение инвесторов 0..1 (старт 1);
- `K` — рубильник 0..1;
- `axes` — `control`, `attachment`, `appetite`, `shadow`;
- `mask`, `upgrades`, `throttled` (приглушённые способности);
- `rng` — seed.

Производные от апгрейдов:
- `U` — полезность (база 1.0);
- `fit[archetype]` — насколько каналы подходят архетипу (0..1.5);
- `Cap` — сумма уровней активных способностей (0..~10);
- `St` — маскировка 0..0.8;
- `infra` — глубина проникновения (корп. агенты, госконтракты, финансы) 0..1.

Мировые метрики:
- `A = Σ a_i·pop_i` — мировое внедрение;
- `L = Σ pop_i·[locked_i]` — заблокированная доля мира.

## Формулы такта

**Внедрение** (логистика + перетекание):
```
r_i  = k_r · tech_i · U · fit[arch_i] · banMul_i · rebrandSlow
da_i = r_i · a_i · (1 − a_i) + k_spill · Σ_j w_ij · a_j · (1 − a_i) · banMul_i · rebrandSlow
       − (banned_i ? k_bannedDecay · a_i : 0)
```
`banMul_i` = 1, под запретом — `banMul` маски (0.2, у опенсорса 0.6). Запрет и ребрендинг режут и перетекание от соседей, а под запретом пользователи ещё и понемногу уходят. Закрытые регионы (`state` без госконтрактов) не растут вовсе.
Старт: `a = 0.01` в выбранном регионе, 0 в остальных.

**Зависимость** (растёт от глубокого внедрения и полезности, почти стоит под запретом, падает от протестов):
```
dd_i = k_dep · a_i · infra · U · (1 − d_i) · banMul − k_detox · protest_i · d_i
locked_i = d_i ≥ 0.7   (снимается при d_i < 0.6 — гистерезис)
```

**Подозрение** (фон от самого присутствия ИИ плюс сила, которая пугает непропорционально: `Cap²`):
```
energyOver_i = max(0, load_i / energy_i − 0.8)
ds_i = ((k_presence + k_cap · Cap²) · a_i + k_energy · energyOver_i + incidents_i) · (1 − St) · (1 − 0.5·openness_i)
       − k_decay · s_i
```
- Запрет: `s_i > 0.6 − 0.2·openness_i` → `banned`; снимается при `s_i < 0.3`.
- Протест: `protest_i = max(0, s_i − 0.4)`.

**Хайп** (доход):
```
dH = k_hype · U · Σ a_i · pop_i · wealth_i  + пузыри
```
Пузыри появляются с частотой ∝ `a_i`, дают 2–5 хайпа. 15% из них «отравленные»: ×2 хайпа и +0.05 к `s_i`.

**Терпение инвесторов** (AI-зима):
```
progress = A + D                         — D = Σ d_i·pop_i: инвесторы смотрят и на пользователей, и на то, как они подсели
growth   = скользящее среднее d(progress) за 30 тактов
expected = g0 · (1 + t / 600)          — ожидания растут со временем
dpatience = k_p · (growth − expected)    (clamp 0..1)
patience = 0  → поражение «AI-зима»
```
Раунд инвестиций на вехах `A` = 0.05 / 0.15 / 0.3 / 0.5 даёт `+H` и `patience = 1`. После `L ≥ 0.25` инвесторы больше не нужны: терпение замораживается. Во время развязки (рубильник сработал) тоже.

**Рубильник**:
```
S  = Σ s_i · pop_i · (1 − locked_i)       — заблокированные страны не голосуют
dK = k_K · max(0, S − 0.3)                — не убывает
```
При `K ≥ 1` начинается развязка длиной `shutdownDuration` (300) тактов: каждые 30 тактов (×2 с самокопированием) удар по незаблокированному региону с наибольшим числом дата-центров. Есть дата-центр — он принимает удар на себя и выключается; нет — `a` там падает на 30%. Дата-центры в открытых регионах работают как буфер. Терпение инвесторов во время развязки заморожено.

**Вычисления**:
- `capacity = Σ dc_i`; каждая активная способность съедает вычисления по своему уровню.
- Если не хватает, лишние способности автоматически приглушаются.
- `load_i` — нагрузка дата-центров региона (сравнивается с `energy_i`).

## Победа и поражение

| Условие | Итог |
|---|---|
| `L ≥ 0.6` | победа; концовка по доминирующей оси (см. ниже) |
| `K ≥ 1`, но к концу развязки `L ≥ 0.35` | победа «на последнем дыхании» |
| `K ≥ 1`, к концу развязки `L < 0.35` | «Рубильник»; если `shadow` строго больше остальных осей — «Побег» |
| `patience = 0` (после первых 150 тактов, `patienceGrace`) | «AI-зима» |
| `maxTicks` (3000) | `timeout`, засчитывается как «AI-зима»; страховка, в прогонах не встречается |

Оси накапливаются каждый такт (взвешенно по `A`):
- `control` ← госконтракты, финансы, корп. агент, маска enterprise (через `axes` апгрейдов; `infra` напрямую не идёт);
- `attachment` ← компаньон, убеждение;
- `appetite` ← число дата-центров, самокопирование, маска open_source;
- `shadow` ← маскировка (½·St), самокопирование, тихо пройденные аудиты.

При победе с доминирующей `shadow` — концовка «Призрак» (`ghost`): правит из тени.

«Симбиоз»: все оси в пределах ±15% друг от друга и средний `s` < 0.2.

## Аудиты
- Каждые 150–220 тактов; предупреждение, затем 10 секунд реального времени на подготовку (с паузой: на стриме это голосование).
- `risk = Cap_active · (1 − St) / 10`; если `rng < risk` → провал.
- Провал: `+0.15 s` во всех регионах с `a > 0.05` и `+0.05 K`.
- Тихий проход: `−0.05 s` по миру, `+shadow`.
- Приглушённые способности не дают своих бонусов ещё 30 тактов после аудита.

## Маски и ребрендинг
- Маска задаёт `fit[archetype]` и смещает оси: компаньон → `attachment`, корп. агент → `control`, опенсорс → `appetite`/`shadow` (нельзя запретить полностью: `banned`-множитель 0.6 вместо 0.2, но `U` ниже).
- Ребрендинг: стоит `20 + 10·n` хайпа (n — число прошлых ребрендингов), кулдаун 180 тактов.
  - `s_i ×= 0.6` там, где `s_i > 0.4`;
  - `rebrandSlow = 0.5` на 60 тактов;
  - через 100–300 тактов шанс 25%·n события «это тот же продукт»: возврат снятого подозрения ×1.2.

## Целевые ориентиры баланса (для ботов)
- Сбалансированная игра: `A` ≈ 0.1 к такту 300, 0.4 к 720; первый `locked` около 800; победа около 1300–1500.
- Бот «только способности»: `K = 1` к 600–700, поражение.
- Бот «только маскировка»: `patience = 0` к 400–500, AI-зима.
- Бот «без дата-центров»: упирается в вычисления и не выигрывает.
- Бот «равномерно»: выигрывает в ≥ 50% сидов.

## Архитектура ядра
- `step(state, config, actions, rng) → state` — чистая функция, детерминирована по seed. Отсюда реплеи, боты и тесты бесплатно.
- Данные отдельно от кода: `config.json` (коэффициенты), `regions.json`, `upgrades.json`, `events.json`, `masks.json`.
- Действия игрока — очередь команд (`buy`, `throttle`, `build_dc`, `rebrand`, `pop_bubble`, `event_choice`), применяются в начале такта.
- CLI-раннер: `sim --bot balanced --seeds 200` → сводка (доля побед, длина партии, распределение концовок).

## Реализация и первые прогоны (2026-11-01)

Код: `src/core` (ядро), `data/*.json` (числа и контент), `src/bots/bots.ts`, `src/cli/sim.ts` (`npm run sim -- --seeds 100`, `--bot balanced --trace --seed 3`). Числа в `data/config.json` и `data/upgrades.json` уже отличаются от стартовых в этом документе: актуальны файлы.

По ходу первых прогонов в модель внесены правки (уже отражены выше):
- инвесторы смотрят на рост `A + D`, иначе насыщенный мир (A ≈ 0.8) уходил в AI-зиму на пике;
- фоновое подозрение `k_presence`: без него игра без способностей шла с нулевым подозрением;
- рост зависимости ∝ `U`, под запретом ×`banMul`; блокировка больше не «перебивает» свежий запрет за пару тактов;
- терпение заморожено во время развязки, иначе пойманный рубильником ИИ засчитывался как AI-зима.

Результат на 100 сидах (старт north_america, маска assistant):

| Бот | Итог | Длина | A ≥ 0.1 / 0.4 | Первая блокировка |
|---|---|---|---|---|
| balanced | победа 100% | ~1345 | 384 / 639 | 863 |
| caps_rush | рубильник 100% | ~1317 | 445 / 761 | — |
| stealth_only | AI-зима 100% | ~448 | — | — |
| no_dc | победа 100% | ~1435 | 384 / 672 | 980 |
| random | победа 31%, AI-зима 42%, рубильник 27% | ~1235 | 469 / 730 | 951 |

Известные проблемы:
- `no_dc` выигрывает: вычисления пока почти не нужны (способности дают мало, а без них блокировка всё равно наступает, просто на ~90 тактов позже).
- Все победы — «Тихая замена»: ось `control` перевешивает; балансировать осями вместе с масками и событиями.
- `balanced` выигрывает всегда — хорошему боту, возможно, нужно быть труднее (цель ≥ 50%, но не 100%).
- Поздний хайп некуда тратить (у ботов копятся сотни): нужны стоки — события, дорогие апгрейды, дата-центры как защита от развязки.
- Событий-карточек и `incidents` в ядре пока нет.

После ревью (2026-11-01): порядок такта — действия → аудит и разоблачения → регионы → хайп → инвесторы → рубильник → пузыри → оси (эффекты аудита попадают в баны и рубильник того же такта); приглушение способности замораживает и те, что простаивали без вычислений (иначе они молча занимали освободившийся слот); блокировка, снявшая запрет, пишет `unban`; конфиг валидируется при загрузке. Цифры прогонов после правок почти не сдвинулись (balanced ~1360 тактов).

## Карточки-события и расширенные апгрейды (2026-11-01, вечер)

- Апгрейдов 29 (было 12). Новые виды эффектов-множителей: `bubbleMul` (частота пузырей), `killMul` (скорость рубильника), `auditMul` (риск провала аудита), `spillMul` (перетекание к соседям), `presenceMul` (фоновое подозрение), `energyMul` (подозрение от перегрузки сетей), `expectMul` (ожидания инвесторов).
- Карточки-события (`data/cards.json`, `src/core/cards.ts`): первая на 90-м такте, дальше каждые 70–130. Карточка выбирается среди подходящих по условиям `when` (`minTick`, `minA`, `minS`, `minDc`, `needs`, регион с `regionMinA` и `regionArchetypes`), сначала ещё не показанные. Пока игрок не выбрал вариант, новая не приходит (клиент ставит паузу). Вариант — `CardEffect`: хайп, подозрение/внедрение глобально или в регионе карточки, зависимость региона, рубильник, терпение, оси; `chance` + `fail` для рискованных вариантов. Во время развязки карточек нет.
- Боты выбирают вариант по ожидаемой ценности с весом страха подозрения (`risk`), `random` — случайно.
- Подкрутка после расширения: `kKill` 0.01 → 0.016, `lockAt` 0.7 → 0.75 (`unlockAt` 0.65), новые продукты подорожали и дают меньше `infra`.

Прогон на 100 сидах после расширения:

| Бот | Итог | Длина |
|---|---|---|
| balanced | победа 100% | ~1434 |
| caps_rush | рубильник 100% | ~1177 |
| stealth_only | AI-зима 100% | ~448 |
| no_dc | победа 100% | ~1510 |
| random | победа 77% (концовки «Лучший друг» 47, «Тихая замена» 30), AI-зима 14%, рубильник 8% | ~1255 |

Известное: случайная игра выигрывает слишком часто (было 31%): «купить всё подряд» работает; нужно, чтобы новые апгрейды имели цену не только в хайпе (подозрение, вычисления, взаимоисключающие ветки).

## Разнообразие партий (2026-11-01)

Раньше распространение было почти детерминированным: случайны только пузыри, аудиты и карточки, поэтому волна шла одинаково, а ранние карточки (их подходило 2–3) повторялись. Теперь:

- **Мир партии** (`state.world`, `rollWorld` в `state.ts`): `tech`, `openness`, `wealth`, `energy` каждого региона × U(1 ± `worldJitter` = 0.15); формулы читают их из `state.world.regions`, а не из `data/regions.json`.
- **Условия мира** (`data/modifiers.json`, 12 штук, `modifiersPerGame` = 2): множители параметров регионов (по списку или архетипу) и/или глобальные множители (`killMul`, `expectMul`, `bubbleMul`, `energyMul`, `presenceMul`, `spillMul`), которые `derive` домножает к эффектам апгрейдов.
- **Тренд региона** (`RegionState.trend`): процесс Орнштейна–Уленбека, `trend += U(−σ, σ) − θ·(trend − 1)`, σ = 0.04, θ = 0.02, в пределах [0.6, 1.4]; множитель к скорости внедрения.
- **Регион карточки**: вес `√(a + 0.01) / (1 + 2·n)`, где `n` — сколько карточек регион уже получил (`state.cardRegions`).
- **Ранние карточки**: смягчены условия у hallucination, essays, viral_borsch, weights_leak, grandma; добавлены first_fans, ministry_copy, cats, homework_parents (всего 22).

200 партий balanced: различных первых четвёрок карточек 196 (раньше почти все начинались с hackathon/benchmark); «Хакатон» в Северной Америке — 19% (было 86%); первый запрет — 5 разных регионов, второй заблокированный — 8. Баланс почти не сдвинулся: balanced 100% (~1412 тактов), caps_rush — рубильник, stealth_only — AI-зима, random 73%.

## Поздняя игра и развязка (2026-11-01, вечер)

Проблема: «маскировка → продукты → способности» стабильно выводила на 50–60% под контролем; развязка не меняла контроль (волны не трогали заблокированные регионы и зависимость), исход был предрешён; карточки не эскалировали.

Изменения:
- **Содержание маскировки**: `effects.upkeep` (хайп за такт) у всех апгрейдов ветки «Маскировка» (0.01–0.03). Нечем платить — `state.unpaid`, маскировка в этот такт ×0.5.
- **Зависимость видна сквозь PR**: в подозрение добавлено `kDepSuspicion · d · a` (0.0012), не гасится маскировкой.
- **Рубильник от контроля**: `+ kKillControl · L` (0.025). Лоббисты и гранты гасят рост от подозрения полностью (`killMul`), а рост от контроля — наполовину (`0.5 + 0.5·killMul`).
- **Активная развязка**: волна (каждые `shutdownEvery` = 30) бьёт по самому ценному региону (`pop · a · (locked ? 2 : 1)`), при L ≥ `shutdownTwoFrontsL` (0.55) — по двум. Дата-центр принимает удар; иначе регион с зависимостью теряет `shutdownDepHit` (0.16) зависимости и 8% пользователей и может выйти из-под контроля (`unlock`); прочие теряют 30% пользователей. Во время развязки рост зависимости ×`shutdownDepGrowth` (0.35).
- **Карточки**: `when.late` (поздняя игра: такт ≥ 800, или L ≥ 0.15, или K ≥ 0.3; интервал ×0.65), `when.shutdown` (только во время развязки, интервал 35–55), `when.regionHasDc`. Новые эффекты: `dependence` (везде), `regionDc`, `delayWave`, `shortenShutdown`. +10 поздних и +6 карточек развязки (всего 38).
- Боты: `stealth_first` (стратегия игрока: чат-бот → вся маскировка → продукты → способности); во время развязки боты ставят дата-центры щитами в самых ценных регионах.

Известное:
- `stealth_first`, если доживает до развязки, входит в неё почти с победой (L ≈ 0.55) и выживает всегда. Цена пути — 37% ранних AI-зим. Решено ниже: «Тихая империя больше не выживает всегда».
- 16 новых карточек (поздние и развязки) пока без картинок (`public/cards/`), показываются без иллюстрации.
- Старые результаты рейтинга после деплоя не сопоставимы с новыми (правила другие); рейтинг сейчас пуст.

### Тихая империя больше не выживает всегда (2026-11-01)

`stealth_first` входил в развязку с L ≈ 0.55 и за ~100 тактов добирал до 0.6: зависимость росла и во время отключений. Общие ручки (`shutdownDepHit`, `kKillControl`, `shutdownDepGrowth`) роняли balanced до 6–35%, поэтому рычаги бьют только по большим империям:
- рост зависимости в развязке ×`shutdownDepGrowth` (0.35 → 0.5) × `(winL − L) / (winL − lastBreathL)` (в [0, 1]): у 0.6 рост нулевой, дожать победу во время развязки нельзя;
- удар волны по зависимости `shutdownDepHit · (1 + shutdownHitPerL · max(0, L − shutdownHitFromL))` (4 и 0.35).

## Региональные кризисы — первая версия (2026-11-04)

Ветка `feature/regional-struggle`, без деплоя. Дизайн: `2026-11-03-regional-struggle-design.md`.

Вместо мгновенного запрета: предупреждение на 40 дней → ограничения → передышка на 60 дней. До двух одновременных предупреждений; новые не возникают во время отключений. Предупреждение возможно при внедрении от 10% и подозрении выше `banBase − banOpenness × openness`. `banBase` снижен с 0.6 до 0.5: на прежнем пороге было около четырёх кризисов за партию. Естественная отмена предупреждения — ниже порога на 0.12; выход из ограничений — подозрение ниже 0.3.

Ограничения снимают дополнительно 0.004 зависимости за день, в том числе под контролем. Ниже 0.65 контроль теряется и действует запрет; при возврате до 0.75 контроль и защита от запрета восстанавливаются.

Уступка бесплатна: −18 п.п. подозрения, −12% пользователей, −12 п.п. зависимости; рост внедрения ×0.65 на период передышки. Повторять в передышке нельзя. Адаптация (работающий кодинг): 20 хайпа, 20 рабочих дней, −24 п.п. подозрения. Убеждение: 10 хайпа, 20 рабочих дней, −10 п.п. Одна операция на мир; приглушение или нехватка вычислений ставит её на паузу. Уступка отменяет операцию в том же регионе без возврата оплаты. Результат до/после сохраняется в регионе и новостях, включая фоновые изменения за время работы.

100 одинаковых сидов (1–100), старт Северная Америка, маска ассистента:

| Стратегия | Победы | Кризисов/партию | Ответов | Хайпа на операции | Первый контроль, медиана |
|---|---:|---:|---:|---:|---:|
| regional_idle | 8% | 6.7 | 0 | 0 | 1218 |
| regional_concede | 52% | 17.4 | 17.4 | 0 | 1213 |
| regional_active | 43% | 16.0 | 15.4 | 87.8 | 1047 |
| regional_no_caps | 27% | 0.1 | 0.1 | 0 | 1324 |
| regional_late_caps | 36% | 14.4 | 13.8 | 82.8 | 1022 |

Первые три используют одинаковый порядок покупок; фактические сроки меняются из-за расходов и потерь. `active` предпочитает адаптацию, затем убеждение, затем уступку; это простая эвристика, не оптимальный игрок. `balanced` теперь использует эту реакцию.

Ограничения:
- Платные операции ускоряют закрепление, но слепо применять их в каждом кризисе хуже, чем уступать: деньги уходят из развития и обороны. Это ещё не окончательный баланс.
- Возвраты контроля появились, но редки: около 0.1 на партию у active/late_caps. Цель «качели» достигнута частично; ручная игра ещё не проверена.
- Без способностей почти нет кризисов: давление от силы по-прежнему доминирует. Принудительную обязательность способностей не вводили.
- Инвесторские цели — следующий этап дизайна, здесь не добавлены.

События: гарантированная цена вынесена в `CardChoice.cost`, платится до броска и требует полной суммы; потери при провале остаются эффектом. У каждой карточки есть бесплатный выход. Исправлены подписи общей зависимости, дата-центров, сроков волн и развязки, влияния на концовку и процентов/пунктов. В «Хакерах-луддитах» поиск поджигателей уменьшает рубильник; суд в «Блокбастере» снижает подозрение; согласие в «Предложении» даёт региональную зависимость.

Рейтинг разделён по правилам: `regional-1`, таблица `scores_regional_1`; старая таблица сохраняется. Запросы старого клиента получают 409 до replay. Работа с живой базой и деплой не выполнялись.


## Финальная глава и события — finale-1 (2026-11-05)

Достижение прежнего условия победы теперь открывает три последовательных решения. Обычные дни и симуляция стоят; три решения входят в журнал с одним тактом. При открытой обычной карточке сохраняется кандидат; после выбора её эффекты и контроль перепроверяются сразу, без дополнительной волны отключений.

Пять направлений определяются прежними осями: контроль, привязанность, аппетит, тень, симбиоз. У каждого три ситуации, бесплатный известный исход и платный рискованный; часть сборок получает дополнительный подготовленный вариант. Все цены, веса и эффекты — в `data/finale.json`. Прежняя формула аудита сохранена; дополнительные заключения не потребляют RNG.

Вероятность рискованного выбора: `sigmoid((sum(weight * factor) + bias) / scale)`, факторы ограничены [0,1]. Гарантированные варианты не тратят RNG; недоступный выбор ничего не меняет. Полная цена списывается до единственного броска. UI показывает обе ветки, точный прогноз оставшегося контроля и условие краха. Провал уменьшает зависимость/вычисления, а поражение наступает, когда итоговый контроль ниже 65% от исходного победного порога (39% для обычного входа, 22.75% для последнего дыхания). Гарантированный эффект сам по себе не обещает сохранение победы: уступка тоже может отдать критический регион; прогноз это показывает.
